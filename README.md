## 🚀 Кроки запуску (30 хвилин)

### Крок 1 — Створити Telegram бота (5 хв)

1. Відкрийте Telegram → знайдіть **@BotFather**
2. Напишіть `/newbot`
3. Введіть назву: `Family Dentists`
4. Введіть username: `family_dentists_bot` (або будь-який вільний)
5. Скопіюйте **токен** (виглядає так: `1234567890:AABBCCDDEEFFaabb...`)

### Крок 2 — Дізнатись свій Telegram ID (2 хв)

1. Напишіть **@userinfobot** у Telegram
2. Він покаже ваш ID (числовий, наприклад: `123456789`)

### Крок 3 — Налаштувати файл .env (3 хв)

```bash
cp .env.example .env
```

Відкрийте `.env` і заповніть:
```
BOT_TOKEN=вставте_свій_токен
ADMIN_IDS=вставте_свій_telegram_id
ADMIN_PASSWORD=придумайте_пароль
```

### Крок 4 — Встановити та запустити (5 хв)

**Варіант А: Локально (для тесту)**

```bash
# Встановити Python 3.11+
pip install -r requirements.txt

# Ініціалізувати базу даних
sqlite3 dentist.db < db/schema.sql

# Запустити бота (термінал 1)
python bot/bot.py

# Запустити веб-панель (термінал 2)
cd web && python app.py
```

Відкрийте браузер: **http://localhost:5000**

---

**Варіант Б: Хмарний деплой на Render.com (безкоштовно)**

1. Зареєструйтесь на **https://render.com** (безкоштовно)
2. Натисніть **New → Web Service**
3. Підключіть GitHub репозиторій або **Paste Code**
4. Налаштування:
   - **Build Command:** `pip install -r requirements.txt && sqlite3 dentist.db < db/schema.sql`
   - **Start Command:** `python bot/bot.py`
5. Додайте змінні середовища (Environment Variables):
   - `BOT_TOKEN` = ваш токен
   - `ADMIN_IDS` = ваш ID
   - `ADMIN_PASSWORD` = пароль
6. Натисніть **Deploy**

> ⚠️ На безкоштовному тарифі Render.com сервіс "засинає" після 15 хв бездіяльності.  
> Для продакшн рекомендується **$7/місяць** план або **PythonAnywhere.com** (безкоштовно).

## 📱 Як користуватися ботом

### Пацієнт
1. Знаходить бота в Telegram → `/start`
2. Натискає **📅 Записатися**
3. Обирає лікаря → дату → час → вказує причину
4. Отримує підтвердження + нагадування

### Адміністратор
- `/admin` — список записів на сьогодні + кнопки "Виконано"
- `/stats` — статистика за день/місяць
- Веб-панель: **http://ваш-сервер:5000**

## 💡 Частіші проблеми

**Бот не відповідає:**
- Перевірте BOT_TOKEN у `.env`
- Переконайтесь що `python bot/bot.py` запущено без помилок

**Веб-панель не відкривається:**
- Переконайтесь що запущено `python web/app.py`
- Відкрийте `http://localhost:5000` (не https)

**База даних порожня:**
- Виконайте: `sqlite3 dentist.db < db/schema.sql`

## 🔧 Додаткові налаштування

### Змінити лікарів
Відредагуйте `db/schema.sql` → секція `INSERT INTO doctors`  
Або виконайте SQL:
```sql
INSERT INTO doctors (name, specialty) VALUES ('Ваш лікар', 'Пародонтолог');
```

### Додати FAQ відповіді
```sql
INSERT INTO faq (keyword, answer) VALUES ('відбілювання', 'Відбілювання зубів від 800 грн. Записуйтесь через бота!');
```

### Змінити години прийому
У файлі `bot/bot.py` знайдіть функцію `get_available_times()` → відредагуйте `all_slots`.
